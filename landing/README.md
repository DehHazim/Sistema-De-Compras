# SIC - Landing Page

Página estática de apresentação do produto. Sem build.

## Rodar

```bash
# abrir direto
open landing/index.html

# ou servir localmente
npx serve landing        # http://localhost:3000
python -m http.server 3000 -d landing
```

## Conteúdo

- Hero com proposta de valor e mock do dashboard
- Problema resolvido (informação dispersa, falta de controle, rastreabilidade, trabalho manual)
- 10 funcionalidades principais
- Benefícios (plataforma única, compliance, menos trabalho manual, tempo real, aprovação configurável, escalabilidade)
- Fluxo em 5 passos (solicitação → aprovação → cotação → pedido → acompanhamento)
- Artefatos e tecnologia do projeto
- CTA para a demonstração (`http://localhost:5173`)

Arquivos: [`index.html`](index.html) + [`styles.css`](styles.css). Fonte Inter via Google Fonts.
